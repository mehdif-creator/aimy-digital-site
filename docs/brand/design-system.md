# Système visuel

Tokens primitifs et sémantiques dans `src/styles/global.css`. Papier froid #f5f7f8, encre #173040, bleu du logo #0686ce, bleu lisible #00649b et texte secondaire #52636c. Le bleu historique est réservé au motif ; les petits textes utilisent une teinte plus sombre.

Manrope local, graisses 400 à 800, polices Latin uniquement. Titres fluides ; corps limité à 68 caractères. Grille maximale 1280 px, marges mobiles 20 px. Espaces de section fluides. Arrondis selon le rôle : boutons en capsule, images et panneaux modérément arrondis.

Composants : Header et MobileNav natif `details`, Button, ServiceCard, ProjectCard, FAQ, CTA, SEOHead, ContactForm, CookieConsent et Footer. Le layout de cas est dans la route portfolio ; pas de composant inutile pour un seul usage.

Clavier : lien d'évitement, focus contrasté, Échap pour refermer le menu. Motion : transform/opacity, désactivée en mouvement réduit. Aucun contenu masqué en attente de JavaScript. Formulaire : validation HTML et serveur, champs étiquetés, état explicite si l'envoi échoue, blocage par défaut sans backend.

Le motif circulaire reprend l'anneau de marque. Le logo source est conservé, sans vectorisation approximative. Les captures montrent uniquement les quatre projets approuvés, sans résultats chiffrés.
