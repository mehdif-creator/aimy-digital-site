# Architecture et contenu

Navigation : Sites internet, SEO local, Réalisations, L'agence, Le journal, Contact.

Accueil : métier et cible locale, réalisations, trois services prioritaires (création/refonte/SEO), méthode, FAQ, contact. CTA principal : Discuter de mon projet.

Services : chemins WordPress conservés pour création, vitrine, e-commerce, refonte, SEO, publicité, maintenance. Chaque service précise audience, contenu de la prestation et déroulé sans prix ni délais inventés.

Portfolio : quatre cas, conformément à PROGRESS.md. Les descriptions reprennent seulement les fonctions visibles/décrites dans le portfolio actuel ; aucun chiffre de résultats et aucun témoignage.

Blog : 11 slugs réels conservés ; huit catégories maintenues. Les catégories vides sont noindex. Les flux et paginations historiques sont encore à arbitrer et bloquent la migration complète.

Légal : les coordonnées de contact sont celles des pages fraîchement inspectées. L'identité juridique, l'adresse publique, la base légale, les durées de conservation, les destinataires, les recours et les informations de l'hébergeur nécessitent validation avant publication. Les pages actuelles de préproduction sont donc incomplètes, sans valeur de validation juridique.
